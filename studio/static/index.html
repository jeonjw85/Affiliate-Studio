Affiliate Studio 기능과 사용 범위

      

        
01
Telegram으로 링크 보내기
본인 계정에서 발급한 쿠팡·토스 제휴 링크를 개인 봇 대화에 전송
상품 정보를 읽으면 설정한 편수와 시간에 맞춰 글 작성·WordPress 예약
페이지를 읽지 못하면 봇 질문에 답장으로 상품명과 특징 전송
쿠팡·토스 발급 API 키는 필요 없음, 자동 운영은 쿠팡 또는 토스 편수 하나 이상 필요
실패한 요청은 같은 링크를 다시 보내 재접수
연결 방법은 README의 Telegram 자동 운영 참고

        
선택
수동 등록과 제휴 API
상품 화면에서 원본 URL 입력 후 '제휴 링크 생성', 또는 발급된 링크 직접 입력
확인한 사실과 가격 확인 시각을 저장한 뒤 초안을 직접 검토·승인
API 발급 주소: 쿠팡 https://www.coupang.com/vp/products/상품ID, 토스 https://toss.shopping/t/상품ID
키: COUPANG_ACCESS_KEY, COUPANG_SECRET_KEY, TOSS_ACCESS_KEY, TOSS_SECRET_KEY, TOSS_PUBLISHER_ID
'설정됨'은 실제 발급 성공과 다름

        
02
템플릿 또는 AI 후보
'초안 만들기'는 템플릿 생성
프로젝트의 .env에서 AI_MODE=local 또는 AI_MODE=api 선택
AI_BASE_URL, AI_MODEL 지정, 외부 API 사용 시 AI_API_KEY 입력
로컬은 모델 서버 실행 필요, API는 OpenAI 호환 HTTPS 서버와 JSON Schema 지원 모델 필요
설정 변경 후 앱 재시작, Docker는 docker compose up -d로 반영
설정 완료는 연결 성공과 다름
콘텐츠의 'AI 연결 확인' 후 표시된 전송 대상과 범위에 동의하고 후보 생성
두 작성 유형의 후보를 원문과 비교·적용한 뒤 직접 검토와 승인 필요
가격·출처·고지는 서버 미리보기에 별도 포함

        
03
승인 후 ZIP 또는 공개 예약
로컬 ZIP 예약은 공개 게시 아님, 앱 서버 실행 중에만 생성
WordPress 공개 예약은 같은 승인본의 원격 초안 전송 후 별도 공개 동의와 시각 확인 필요
예약 탭에서 마지막 조회 시각과 결과 확인
공개 예약·전송 중·결과 불명 상태의 글과 관련 상품은 수정 잠금
취소는 WordPress 관리자에서 예약 글을 초안으로 변경한 뒤 앱의 원격 상태 조회로 확인, 앱 직접 취소 미지원

        
선택 사항
WordPress 연결
서버 환경 변수 WP_URL, WP_USERNAME, WP_APP_PASSWORD로 연결
이 화면에는 애플리케이션 비밀번호 입력·표시 안 함
'초안으로 전송'은 비공개, '공개 게시 예약'은 실제 외부 공개 예약
PC 종료 후에도 원격 예약 유지, WordPress cron에 따라 발행 지연 가능
WordPress 연결 없이도 상품·콘텐츠·ZIP 기능 사용 가능

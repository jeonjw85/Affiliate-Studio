WordPress·네이버·티스토리·기타 채널에서 직접 확인한 수치를 비교합니다. 이 목록은 자동 수집이나 수익 보장이 아닙니다.

      
수동 입력 · 금액은 원화(KRW). 보고서의 같은 기간·시간대·귀속 기준을 사용하세요. 모르는 값은 비워두고, 확인한 0만 0으로 입력합니다. 서로 겹치는 기간을 더하거나 조건이 다른 채널을 단순 순위화하지 않습니다.

01
상품 정보와 링크 입력
쿠팡 파트너스 또는 토스에서 직접 발급한 본인의 제휴 URL을 입력하세요. 원본 URL, 확인한 사실, 가격 확인 시각을 기록합니다.
상품 수집, 제휴 링크 발급, 매출·수익 추적은 제공하지 않습니다. 토스 제휴 정책은 확인되지 않았으므로 직접 검토해야 합니다.

        
02
템플릿 또는 로컬 AI 후보
초안 만들기는 템플릿 생성입니다. 선택적으로 로컬 OpenAI 호환 서버를 실행하고 앱 서버 환경 변수 AI_BASE_URL, AI_MODEL을 지정하세요. 루프백 로컬 서버만 지원하며 유료 API나 API 키는 필요하지 않습니다.
설정됨은 연결 성공이 아닙니다. 콘텐츠에서 ‘AI 연결 확인’ 후 전송 범위에 동의하고 후보를 만드세요. 두 작성 유형의 후보를 원문과 비교한 뒤 적용하고 직접 검토·승인합니다. 가격·출처·고지는 서버 미리보기에 별도 포함됩니다.

        
03
승인 후 ZIP 또는 공개 예약
로컬 ZIP 생성 예약은 공개 게시가 아닙니다. 앱 서버가 실행 중일 때만 패키지를 만듭니다. WordPress 공개 예약은 같은 승인본의 원격 초안 전송 후 별도의 공개 동의와 시각 확인이 필요합니다.
예약 탭에서 마지막 조회 시각과 결과를 확인하세요. 공개 예약·전송 중·결과 불명 상태의 글과 관련 상품은 수정이 잠깁니다. 취소는 WordPress 관리자에서 예약 글을 초안으로 되돌린 뒤 앱의 원격 상태 조회로 확인하세요. 앱에서 직접 취소하지 않습니다.

        
선택 사항
WordPress 연결
서버 환경 변수 WP_URL, WP_USERNAME, WP_APP_PASSWORD로 연결합니다. 애플리케이션 비밀번호는 이 화면에 입력하거나 표시하지 않습니다.
‘초안으로 전송’은 공개하지 않습니다. ‘공개 게시 예약’은 실제 외부 공개를 예약합니다. 원격 예약은 PC 종료 후에도 유지되며 WordPress cron에 따라 지연될 수 있습니다. 연결하지 않아도 상품·콘텐츠·ZIP 기능을 사용할 수 있습니다.
